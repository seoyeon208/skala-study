머신러닝 복습 노트

규칙 기반 방식과 머신러닝의 차이부터 Decision Tree·Ensemble·KNN·SVM·Clustering, 그리고 신경망이 오차를 줄이며 학습하는 과정까지 연결했습니다. 목표는 알고리즘 이름을 외우는 것이 아니라 어떤 데이터와 문제에서 왜 이 모델을 선택하고 어떻게 학습되는지 설명하는 것입니다.

01

왜 머신러닝인가

사람이 규칙을 모두 적는 대신 데이터에서 반복되는 패턴을 학습
▸

Rule-based와 Machine Learning

구분Rule-basedMachine Learning
판단 기준사람이 조건과 임계값을 정의과거 데이터에서 관계와 패턴을 학습
복잡한 상호작용규칙 수가 빠르게 늘어남여러 변수의 조합을 모델이 표현
새 데이터 반영규칙을 직접 수정데이터를 추가해 재학습
사람의 역할모든 규칙 설계문제·데이터·지표·모델을 올바르게 정의

대출 연체를 예측할 때 소득·부채·연체 횟수마다 사람이 임계값을 만드는 대신, 과거 고객의 입력 X와 실제 연체 여부 y를 이용해 관계를 학습할 수 있습니다.

가장 중요한 관점

모든 모델은 현실의 근사입니다. 좋은 모델은 학습 데이터를 완벽히 외운 모델이 아니라 보지 못한 데이터에서도 쓸모 있게 일반화하는 모델입니다. 예측값을 100% 진실로 받아들이지 않고 한계와 불확실성을 함께 봅니다.

LLM과의 관계

LLM이 모든 문제를 대체하는 것은 아닙니다. 결과를 세밀하게 통제하고 예측 가능하게 운영해야 하는 기업 문제에서는 전통적인 머신러닝과 LLM을 목적에 따라 조합합니다.

학습 방식·예측 과제·모델 계열은 서로 다른 축
▸
Learning paradigm
정답 유무에 따라 지도·비지도·준지도 학습
Prediction task
범주를 고르는 Classification, 연속값을 맞추는 Regression
Model family
Linear·Instance·Kernel·Tree·Ensemble·Neural Network 등 작동 원리에 따른 계열

Decision Tree는 지도학습이면서 분류와 회귀에 모두 쓰이고, 모델 계열로는 Tree-based입니다. 한 알고리즘이 세 축에서 각각 다른 이름을 갖습니다.

Regression은 “연속값 예측 과제”와 “회귀 모델 계열” 두 뜻으로 쓰입니다. Logistic Regression은 이름에 Regression이 있지만 확률을 임계값으로 나눠 분류에 사용합니다.

03

학습·검증·일반화

Train·Validation·Test의 역할을 섞지 않는다
▸
데이터역할사용 시점
Train모델 파라미터 학습반복 사용
Validation모델·하이퍼파라미터 선택개발 중 반복 확인
Test최종 일반화 성능 평가선택이 끝난 뒤 한 번

같은 Validation만 계속 보면 그 데이터에도 과적합될 수 있습니다. K-Fold Cross Validation은 Train을 여러 조합으로 나눠 검증 점수를 평균내므로 한 번의 우연한 분할보다 안정적입니다. 최종 Test는 학습과 선택 과정에 개입시키지 않습니다.

상태Train 오차Validation 오차해석
Underfitting큼큼모델이 너무 단순·학습 부족, High Bias
적절낮음조금 더 낮지 않음새 데이터에도 패턴이 유지
Overfitting매우 작음다시 커짐Train을 암기, High Variance
Learning curve 읽기

Train 오차는 계속 줄지만 Validation 오차가 올라가기 시작하면 과적합 신호입니다. 두 오차가 모두 높으면 더 복잡한 모델·유용한 Feature·충분한 학습이 필요할 수 있습니다.

04

트리는 어떻게 판단하나

큰 결정을 작은 질문으로 나누는 재귀적 분할
▸
Root node
전체 데이터에서 첫 질문을 시작하는 노드
Internal node
Feature와 임계값으로 다음 분기를 만드는 노드
Leaf node
최종 클래스 또는 평균 예측값을 내는 노드
  1. 각 Feature의 가능한 임계값을 후보로 만든다.
  2. 후보마다 왼쪽·오른쪽 데이터를 나눈다.
  3. 회귀는 오차, 분류는 불순도를 계산한다.
  4. 가장 많이 개선되는 분할을 선택하고 자식 노드에서 반복한다.
  5. 종료 조건에 도달하면 Leaf의 예측값을 결정한다.

트리의 경계는 Feature 축과 평행한 선들이 이어진 계단 모양입니다. 깊이를 제한하지 않으면 샘플 하나마다 칸을 만들 수 있어 Train 오차는 0에 가까워지지만 일반화는 나빠질 수 있습니다.

해석 가능성

어떤 질문을 순서대로 거쳐 예측했는지 확인할 수 있고 Feature Importance도 얻기 쉽습니다. 다만 데이터가 조금만 바뀌어도 트리 구조가 크게 바뀌는 불안정성이 있습니다.

05

분할 기준과 과적합

회귀는 오차, 분류는 불순도를 줄이는 방향
▸ 
회귀: MSE = (1/n) Σ(yᵢ - ŷ)²
분류: Gini = 1 - Σpᵢ²
분류: Entropy = -Σpᵢ log₂pᵢ
Information Gain = 부모 불순도 - 가중 자식 불순도

회귀 Leaf는 보통 그 안의 Target 평균을 예측하고 평균제곱오차가 가장 작아지는 분할을 고릅니다. 분류는 한 노드에 클래스가 얼마나 섞였는지 Gini나 Entropy로 측정해 불순도가 가장 많이 줄어드는 분할을 고릅니다.

제어 방법의미
max_depth최대 깊이 제한
min_samples_split분할하려면 필요한 최소 샘플
min_samples_leafLeaf에 남겨야 할 최소 샘플
Pruning효용이 작은 가지를 잘라 복잡도 축소
Scaling이 보통 필요 없는 이유

트리는 각 Feature 안에서 값의 순서와 임계값을 비교합니다. 서로 다른 Feature의 거리를 직접 합치지 않으므로 단위가 달라도 분할 순서는 변하지 않습니다. 반대로 KNN·SVM·K-Means는 거리 계산 때문에 Scaling이 중요합니다.

06

Bagging과 Boosting

약한 모델을 결합하지만 학습 순서와 줄이려는 오류가 다르다
▸
구분BaggingBoosting
학습Bootstrap 표본으로 여러 모델을 독립·병렬 학습이전 모델의 오차를 다음 모델이 순차 보완
결합분류 Voting, 회귀 Averaging학습률과 모델별 기여도를 가중 합산
주효과Variance 감소, 안정성 향상Bias 감소, 어려운 패턴 보완
대표Random ForestGradient Boosting·XGBoost·LightGBM·CatBoost

Stacking은 서로 다른 모델의 예측값을 다시 Meta Model의 입력으로 사용합니다. 대회에서는 강력할 수 있지만 운영 복잡도와 설명 비용이 늘어 실제 업무에서는 이득을 확인하고 선택합니다.

반드시 구분

Bagging은 서로 다른 표본으로 만든 트리들을 동시에 평균내고, Boosting은 앞 모델이 틀린 부분을 다음 모델이 이어서 보완합니다.

07

Tree Ensemble 비교

Random Forest·XGBoost·LightGBM·CatBoost의 선택 기준
▸
모델핵심잘 맞는 상황·주의
Random ForestBootstrap + 무작위 Feature로 여러 트리 평균안정적인 기준 모델, 병렬화 쉬움
XGBoostGradient Boosting에 규제·결측 처리·병렬 최적화정형 데이터에서 강력, 튜닝 항목이 많음
LightGBMLeaf-wise 성장과 histogram대용량·고차원에서 빠름, 작은 데이터는 깊은 Leaf 과적합 주의
CatBoostOrdered target statistics로 범주형 처리범주형 Feature가 많을 때 편리, 학습 비용 비교 필요

Boosting에서 자주 보는 하이퍼파라미터는 n_estimators, learning_rate, max_depth, subsample, colsample_bytree, 규제값입니다. 작은 learning rate는 보통 더 많은 tree가 필요합니다.

모델 선택을 설명하는 법

“점수가 1등이라서”만으로 끝내지 않습니다. 데이터 크기·범주형 비율·학습/추론 시간·해석 가능성·과적합 위험과 검증 결과를 함께 말해야 합니다. 같은 계열 모델만 여러 개 돌리기보다 성질이 다른 기준 모델도 비교합니다.

08

거리·유사도

닮음을 어떤 숫자로 정의하느냐가 이웃과 군집을 바꾼다
▸
측정법핵심적합한 예
Jaccard교집합/합집합, 둘 다 0인 항목 제외구매 여부·태그 같은 이진 희소 데이터
Manhattan (L1)Σ|xᵢ-yᵢ|격자 이동·고차원 희소 데이터
Euclidean (L2)√Σ(xᵢ-yᵢ)²연속형 좌표의 직선거리
Cosine similarity(A·B)/(|A||B|), 크기보다 방향길이가 다른 문서·임베딩

정규화된 유사도가 0~1이면 1 - similarity를 거리로 바꿀 수 있지만, 범위가 정해지지 않은 모든 distance에 같은 식을 적용할 수는 없습니다. Minkowski distance는 p=1이면 Manhattan, p=2이면 Euclidean입니다.

Cosine과 내적

두 벡터를 정규화하면 내적이 Cosine similarity가 됩니다. 방향이 같을수록 값이 크고 직교하면 0입니다. 문서 길이를 제외하고 주제 방향을 비교할 수 있어 자연어와 Transformer의 유사도 계산에 연결됩니다.

09

KNN

새 데이터와 가장 가까운 과거 사례 K개로 판단
▸

K-Nearest Neighbors는 별도의 예측식을 만드는 대신 학습 데이터를 그대로 보관하는 lazy learning·instance-based learning입니다. 분류는 이웃의 다수결, 회귀는 평균으로 예측합니다.

input새 샘플
→
distance모든 거리 계산
→
select가까운 K개
→
aggregate투표·평균
선택효과
K가 너무 작음노이즈에 민감, 복잡한 경계, Overfitting
K가 너무 큼지역 특성을 잃고 다수 클래스 쪽으로 평활화, Underfitting
Distance weighting더 가까운 이웃에 큰 가중치
Feature·instance selection무관한 축과 품질 낮은 사례 제거
Scaling은 필수에 가깝다

나이가 20~60이고 소득이 수천만 단위라면 Scaling 전에는 소득이 거리를 거의 지배합니다. 또한 차원이 커질수록 가까움의 차이가 흐려지는 curse of dimensionality가 생깁니다.

학습은 빠르지만 예측마다 저장된 샘플과 거리를 계산하므로 데이터가 커질수록 메모리와 추론 시간이 증가합니다. 빠른 응답이 필요한 대규모 서비스에서는 한계가 뚜렷합니다.

10

SVM

경계와 가장 가까운 Support Vector 사이의 Margin을 최대화
▸

Support Vector Machine은 단순히 두 클래스를 가르는 선이 아니라, 양쪽 클래스의 가장 가까운 점들과 경계 사이 거리인 Margin이 최대가 되는 hyperplane을 찾습니다. 최종 경계를 결정하는 가까운 샘플이 Support Vector입니다.

개념의미
Hard margin오분류를 허용하지 않음, 깨끗한 선형 분리 데이터에 제한
Soft marginslack variable로 일부 위반을 허용해 노이즈에 대응
C가 큼위반을 강하게 벌점, 좁고 복잡한 경계·과적합 위험
C가 작음더 많은 위반 허용, 넓은 Margin·단순한 경계

Kernel trick

원래 공간에서 선형 분리가 안 되는 데이터를 고차원 Feature 공간으로 보낸 것처럼 계산해 선형 경계를 찾습니다. linear는 변환 없이 선형 경계를, 기본적으로 많이 쓰는 RBF는 비선형 경계를 만듭니다.

핵심 세 가지

Support Vector로 경계 결정 → C로 오분류 허용 정도 조절 → Kernel로 비선형 문제 확장의 연결을 기억합니다. 거리 기반이므로 Scaling이 중요하고, 큰 데이터에서는 학습 비용이 커질 수 있습니다.

11

K-Means

K개의 중심과 가까운 샘플을 반복해서 묶는 분할 군집법
▸
  1. 분석가가 군집 수 K를 정하고 K개의 초기 centroid를 잡는다.
  2. 각 샘플을 가장 가까운 centroid의 군집에 할당한다.
  3. 군집별 평균으로 centroid를 다시 계산한다.
  4. 할당이나 centroid가 거의 변하지 않을 때까지 반복한다.
장점한계
빠르고 이해·해석이 쉬움K를 미리 정해야 함
대규모 데이터에도 비교적 효율적초기값·이상치·Scaling에 민감
중심 기반 프로파일링 편리초승달처럼 비구형이거나 밀도가 다른 군집에 약함
거리 모델의 공통점

Feature 단위가 다르면 큰 숫자의 Feature가 centroid와의 거리를 지배합니다. K-Means 전에 Scaling하고 여러 초기값으로 실행해 안정성을 확인합니다.

12

계층적 군집·DBSCAN

병합 과정 또는 밀도로 K-Means가 놓치는 구조를 찾는다
▸

Hierarchical clustering

Feature Engineering에서 Representation Learning으로
▸
구분전통적 머신러닝딥러닝
Feature사람이 도메인 지식으로 설계·선택여러 Layer가 유용한 표현을 단계적으로 학습

구조상대적으로 단순하고 해석하기 쉬움표현 학습과 예측을 하나의 네트워크에서 함께 수행
비용작은 데이터에서도 강한 경우가 많음대량 데이터·연산 자원·실험 비용이 큼

낮은 Layer는 픽셀의 선·모서리처럼 단순한 특징을, 더 깊은 Layer는 모양과 객체처럼 결합된 특징을 학습합니다. 이를 Representation Learning이라고 합니다.

가장 중요한 관점

딥러닝이 Feature Engineering을 줄여 주지만 사람의 판단을 없애지는 않습니다. 데이터 품질·네트워크 구조·손실함수·학습률·정규화까지 오히려 실험할 요소가 많습니다. 먼저 단순한 구조로 기준 성능을 만든 뒤 복잡도를 늘립니다.

실무에서 놓치기 쉬운 점

딥러닝은 선형회귀처럼 엄격한 데이터 가정이 적지만, “전처리가 필요 없다”는 뜻은 아닙니다. Scaling·결측 처리·시계열 정렬처럼 문제에 맞는 준비를 했을 때 학습이 더 안정적인 경우가 많습니다.

미분과 연쇄법칙

현재 위치에서 어느 방향으로 얼마나 바꿔야 하는지 계산
▸

미분값은 한 점에서 입력이 조금 변할 때 출력이 얼마나 변하는지를 나타내는 순간 기울기입니다. 기울기가 양수면 x를 늘릴 때 함수값이 커지고, 음수면 작아집니다.

평균 변화율: Δy / Δx
미분계수:     f'(x) = lim[h→0] {f(x+h)-f(x)} / h
연쇄법칙:     dy/dx = (dy/dz) × (dz/dx)

신경망은 여러 함수가 층층이 합성된 구조입니다. 연쇄법칙은 마지막 Loss에서 시작해 중간 계산의 미분값을 곱하며 각 Weight가 Loss에 준 영향을 구합니다.

수식을 읽는 핵심

∂L/∂w는 “Weight w를 아주 조금 바꾸면 Loss L이 얼마나 변하는가?”입니다. 역전파는 새로운 마법 공식이 아니라 이 미분값을 뒤에서 앞으로 효율적으로 전달하는 과정입니다.

순전파·Loss·역전파

예측하고 오차를 잰 뒤 책임을 뒤로 전달해 Weight를 수정
▸
forward예측 계산
→
loss정답과 비교
→
backwardGradient 계산
→
updateWeight 수정
↺
  1. 순전파: 현재 Weight와 Bias로 입력부터 출력까지 계산합니다.
  2. Loss 계산: 예측과 정답의 차이를 하나의 숫자로 측정합니다.
  3. 역전파: 연쇄법칙으로 각 Weight의 Gradient ∂L/∂w를 구합니다.
  4. 업데이트: Loss가 줄어드는 반대 방향으로 Weight를 조금 이동합니다.
w_new = w_old - learning_rate × ∂L/∂w

Gradient의 부호는 움직일 방향을, 절댓값은 그 Weight가 Loss에 미치는 민감도를 알려 줍니다. 역전파의 출발점은 항상 최종 Loss이며, 학습은 이 과정을 반복해 오차를 줄이는 일입니다.

Gradient Descent 직관

산의 현재 위치에서 가장 가파르게 올라가는 방향이 Gradient라면, 최솟값을 찾으려면 그 반대 방향으로 내려갑니다. 한 번에 최솟값을 계산하는 것이 아니라 조금씩 이동하며 찾습니다.

Common traps

헷갈리는 포인트 총정리

비슷한 용어가 실제로 무엇을 다르게 뜻하는지 확인합니다.

Parameter ≠ Hyperparameter

Parameter는 데이터에서 학습되고, Hyperparameter는 학습 전에 사람이 정해 검증으로 선택합니다.

Classification ≠ Clustering

Classification은 정답 라벨을 학습해 범주를 예측하고, Clustering은 라벨 없이 데이터 구조를 묶습니다.

Bagging ≠ Boosting

Bagging은 독립 모델을 평균내 Variance를 줄이고, Boosting은 이전 오차를 순차 보완해 Bias를 줄입니다.

Distance ≠ Similarity

거리는 작을수록, 유사도는 클수록 닮았습니다. 변환 가능 여부는 값의 범위를 확인해야 합니다.

Train score ≠ Generalization

Train 점수가 높아도 Validation·Test 성능이 벌어지면 학습 데이터를 외운 과적합입니다.

높은 군집 점수 ≠ 유용한 군집

내부 지표뿐 아니라 군집 크기·안정성·업무에서 다른 행동을 할 수 있는지까지 확인합니다.

Feature Learning ≠ 자동 해결

딥러닝이 표현을 학습해도 데이터 품질·구조·손실함수·학습 설정은 사람이 설계하고 검증합니다.

Forward ≠ Backpropagation

순전파는 예측을 계산하고, 역전파는 Loss에서 출발해 각 Weight의 Gradient를 계산합니다.

Batch ≠ Epoch

Batch는 한 번 업데이트에 쓰는 묶음이고, Epoch는 전체 Train 데이터를 한 번 모두 본 횟수입니다.

Dropout Train ≠ Inference

학습 중에는 일부 Node를 끄지만 실제 예측에서는 모든 Node를 사용합니다.
