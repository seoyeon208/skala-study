▸
Controller언제 선택하나핵심 특성

StatefulSet안정적 이름·순서·개별 볼륨 필요고정 identity, Headless Service, PVC template
DaemonSetNode마다 Agent 하나로그·보안·네트워크 Agent

실무 판단

06

Scheduling과 배치 제어

조건이 많아질수록 Pending 가능성도 함께 커진다
▸
도구의미주의점
nodeSelector정확히 일치하는 Node label가장 단순하지만 조건이 좁으면 Pending
nodeAffinity필수(required)·선호(preferred) 조건필수 조건은 만족할 Node가 꼭 있어야 함
podAntiAffinity같은 앱을 서로 떨어뜨림장애 분산, Scheduling 비용
topologySpreadConstraintsAZ·Node에 균등 분산maxSkew와 unsatisfiable 정책 이해
taint / tolerationNode 출입금지와 Pod 입장권toleration은 배치를 보장하지 않음
PriorityClass자원 부족 시 우선순위·선점데이터 처리 작업의 갑작스러운 축출 주의
중요 구분

Affinity는 “어디를 선호하거나 요구하는가”, Taint는 “이 Node에 아무나 들어오지 못하게 하는가”입니다. 전용 GPU·시스템 Node처럼 격리 자체가 목적이면 taint와 toleration이 핵심입니다.

HPA가 Pod를 늘려도 Node에 자리가 없으면 Pending입니다. 그 다음 단계에서 Cluster Autoscaler나 Karpenter가 Node를 늘립니다. HPA → Node autoscaling 순서를 구분합니다.

설정과 Secret

설정을 이미지에서 분리하고 변경 반영 방식까지 설계
▸
주입 방식변경 시 동작언제 사용하나
환경 변수기존 Pod에는 반영되지 않음기동 시 한 번 읽는 작은 설정
ConfigMap/Secret 볼륨파일이 일정 시간 뒤 갱신앱이 파일을 다시 읽을 수 있을 때
subPath 파일자동 갱신되지 않음단일 파일 경로가 꼭 필요할 때
Rollout restart새 Pod가 새 설정을 읽음환경 변수·재기동 필요 앱

Kubernetes Secret의 값은 기본적으로 base64 인코딩일 뿐 암호화가 아닙니다. etcd 암호화, RBAC 최소 권한, 감사 로그를 적용하고 실제 비밀은 AWS Secrets Manager와 External Secrets 같은 방식을 검토합니다.

2026 기준 보완

Git에 평문 Secret을 넣지 않습니다. 런타임에는 장기 Access Key보다 EKS Pod Identity 또는 IRSA처럼 ServiceAccount와 IAM Role을 연결한 임시 자격 증명을 우선합니다.

수업 강조

설정 파일이 바뀌었다고 애플리케이션 동작까지 자동으로 바뀌는 것은 아닙니다. 주입 방식과 앱의 reload 지원 여부를 함께 확인합니다.

자주 헷갈리는 포인트

Phase vs Ready

Running이어도 readiness가 실패하면 Service 트래픽을 받지 않습니다.

requests vs limits

requests는 배치·예약, limits는 실행 중 상한입니다. CPU와 메모리의 초과 결과도 다릅니다.

HPA vs Node 확장

HPA는 Pod 수, Karpenter·Cluster Autoscaler는 Node 용량을 늘립니다.

Service vs Ingress

Service는 안정적인 L4 접근점, Ingress는 외부 HTTP 경로 규칙이며 Controller가 실제 실행합니다.

EBS vs EFS

EBS는 AZ와 RWO 제약이 있고 EFS는 여러 Node가 공유할 수 있지만 지연·비용 특성이 다릅니다.

Secret vs 암호화

base64는 인코딩입니다. 저장 암호화·RBAC·외부 Secret 관리가 별도로 필요합니다.

RBAC vs IAM

RBAC는 Kubernetes API 권한, IAM은 AWS API 권한입니다. Pod는 두 경계를 모두 만날 수 있습니다.

Probe vs Monitoring

Probe는 Kubernetes의 즉시 판단 신호이고 관측성은 장기 추세·원인·사용자 영향을 설명합니다.
